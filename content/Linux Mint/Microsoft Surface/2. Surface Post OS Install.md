# Configure Surface Kernel

> [!NOTE]
> Full instructions [here](https://github.com/linux-surface/linux-surface).

Assuming a Debian based distro (like Mint):

```sh
# Import keys used to sign packages
wget -qO - https://raw.githubusercontent.com/linux-surface/linux-surface/master/pkg/keys/surface.asc | gpg --dearmor | sudo dd of=/etc/apt/trusted.gpg.d/linux-surface.gpg
# Add repository configuration
echo "deb [arch=amd64] https://pkg.surfacelinux.com/debian release main" 	| sudo tee /etc/apt/sources.list.d/linux-surface.list
# Update APT
sudo apt update
# Install linux-surface kernel and dependencies
sudo apt install linux-image-surface linux-headers-surface libwacom-surface iptsd
```

Configure secure boot:

```sh
sudo apt install linux-surface-secureboot-mok
```

Reboot, then a blue menu (MokManager) should pop up, asking you whether you want to enroll the key. Confirm with `ok`/`yes` and when asked for a password enter `surface`.

> [!NOTE]
> If you don't get the blue MokManager screen, then reinstall secure boot:
> ```sh
> sudo apt remove linux-surface-secureboot-mok
> sudo apt install linux-surface-secureboot-mok
> sudo update-grub
> ```

# Configure external monitor

> [!NOTE]
> The Surface Pro 5 model is not able to output to many high resolutions, at least not directly. The alternative is to use an external USB dongle with 4K HDMI output. Even then, these dongles might only be able to output to the massive Samsung 49" ultra-wide monitor with a slow frequency of 30 Hz, which is very noticeable.

In the case of the Samsung 49" ultra-wide monitor, the correct configuration can be achieved with:

```sh
xrandr --output HDMI-2 --mode 5120x1440 --fbmm 1193x336 --pos 0x0 --scale 2x2 --output eDP-1 --mode 2736x1824 --fbmm 260x173 --pos 3200x2880 --scale 1x1
```

> [!NOTE]
> The above assumes that internal display is called `eDP-1` and the external display is called `HDMI-2`. If not, check the correct names by running `xrandr`.
